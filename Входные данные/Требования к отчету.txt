Цель практики: изучение основ работы с реляционными базами данных c использованием языка Python и СУБД SQLight.

Методические материалы, содержание этапов практики изложены в прилагаемом практическом руководстве.

Особенность практики состоит  в том, что по ней нет аудиторных занятий и консультаций. Основа – самостоятельная работа студентов.

Отметим, что освоение основ работы с СУБД в рамках практики осуществляется параллельно с изучением языка Python по дисциплине «Программное обеспечение автоматизированных систем», по которой есть лекции и практические занятия.

Практика включает 4 этапа. Этапы изложены в практическом руководстве.

По 1 этапу отчетности нет. По этапам 2-4 каждый студент присылает отчет для проверки и оценки руководителю практики по ОСЭП. Эти три отдельных отчета  затем включаются в итоговый отчет.

Для выполнения 4 этапа разрабатывается программа по индивидуальному заданию, номер варианта задания будет доведен до студента позже.  Для разработки программы используются готовые данные, они находятся в базе данных Vuz.sqlite , файл прилагается к этому письму.

Контрольные мероприятия по прохождению практики определены в БАРС.

В БАРС каждому из вас уже размещено общее задание на практику.  Не позднее 1-й учебной недели каждому из вас необходимо по этому заданию проставить отметку «ознакомлен», что эквивалентно электронной подписи о принятии задания к выполнению. В этом случае за КМ-1 будет выставлена положительная оценка.

КМ-2 проставляется на 8-й учебной неделе. Для получения минимальной положительной оценки (3 балла) необходимо выполнить и отчитаться по выполнению 2-го этапа практики.   Для получения максимальной  положительной оценки (5 баллов) необходимо выполнить и отчитаться по выполнению 2-го и 3-го этапам практики. 

Отчеты по этапам прохождения практики должны включать тексты команд, тексты разработанных программ, протоколы работы программ, скриншоты.

Оценки по остальным КМ выставляются на 16-й неделе по результатам выполнения задания полностью.

Завершение практики.

Итоговый отчет, включающий ранее принятые руководителем практики отчеты по отдельным этапам, размещается студентом в БАРС как «отчеты студентов»   по практике. Формат pdf.   

По проверенным и принятым отчетным материалам и оценкам за  КМ  выставляется общая семестровая зачетная оценка.  

Последний день размещения отчетных материалов – 16 учебная неделя, предпоследний учебный день, до 15 час.  Конкретная дата будет уточнена позже. Все не уложившиеся в срок студенты получают неудовлетворительную оценку за практику и ликвидируют задолженность по регламентам повторных промежуточных аттестаций.
